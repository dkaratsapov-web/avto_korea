## Инструменты проверки живого сайта
- Сайт из облачной сессии напрямую не открывается (сеть). Браузер на GitHub: workflow **Site shots** (Actions → Run workflow, или правка `site-shots.txt`) → скриншоты и отчёт в ветке `site-shots`: `git fetch origin site-shots && git show origin/site-shots:README.md`. В отчёте — ошибки, упавшие запросы, чужие скрипты и кто их вызвал.
- **Site check** — каждый день: срок SSL (падает, если < 14 дней), ответы сайта, вебхук Telegram.
