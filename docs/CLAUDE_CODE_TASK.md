# Задача для Claude Code — сайт «ДиАвто69»

Этот файл — готовое задание для **Claude Code**. Положите его в корень проекта вместе с двумя ассетами и запустите Claude Code (инструкция в самом низу).

## Ассеты в репозитории
- `diauto69_site.html` — **рабочий макет** (Hero + блок «Наличие»). Эталон визуала, цветов, типографики и карточки авто. Перенести в код **1:1 по стилю**.
- `ТЗ_DI_AUTO_69_сайт.md` — полное ТЗ: структура всех 10 секций, дизайн-система, UI-кит, критерии готовности.

> Правило: `diauto69_site.html` — источник истины по визуалу; `ТЗ_DI_AUTO_69_сайт.md` — источник истины по объёму и структуре. При конфликте — уточнить у заказчика.

---

## 1. Цель
Лендинг для импорта авто из 🇰🇷🇨🇳🇯🇵🇪🇺 «под ключ». Главное действие — **заявка на расчёт стоимости**. Премиальная, доверительная подача; бренд: бордо + хром + графит.

## 2. Рекомендуемый стек
- **Next.js (App Router) + TypeScript + Tailwind CSS** — SEO, формы, простой деплой на Vercel.
- Tailwind с кастомными токенами (ниже). Шрифты — `next/font` (Google): Saira Condensed (display), Saira (числа/цены), Manrope (текст).
- Иконки — `lucide-react`. Анимации — лёгкие, на CSS / Framer Motion по минимуму.
- Состояние не нужно сложное; данные авто — из локального `data/cars.ts` (позже можно вынести в CMS).
- Альтернатива, если важнее скорость/простота: **Astro + Tailwind** (отличный SEO для лендинга, фильтр — на островке).

## 3. Что построить (все секции из ТЗ)
В порядке приоритета:
1. `Header` (sticky, лого, навигация-якоря, CTA «Рассчитать авто», телефон, бургер на мобайле)
2. `Hero` (графит, H1, 3 бейджа, форма заявки, флаги, авто-визуал)
3. `Advantages` (4–6 карточек «почему мы»)
4. `HowItWorks` (5–6 шагов процесса)
5. `Catalog` (табы-фильтр по странам + сетка `CarCard`, «показать ещё»)
6. `Calculator` / форма расчёта (страна, модель, год, бюджет, контакт)
7. `Geography` (маршруты стран + сроки)
8. `Reviews` (карусель + кейсы «доставлено»)
9. `FAQ` (аккордеон)
10. `FinalCTA` (графит, форма) + `Footer` + плавающая кнопка Telegram

**Переиспользуемые компоненты:** `Button`, `CarCard`, `LeadForm`, `Badge`, `Accordion`, `Tabs`, `SectionHeading`, `CarSilhouette` (SVG из макета).

## 4. Дизайн-токены (Tailwind `theme.extend`)
```
colors:
  graphite: '#11151A'   graphite2: '#1B222B'
  bordeaux: '#7A1410'   bordeauxDeep: '#530700'  bordeauxBright: '#9C1A12'
  steel: '#5C6D76'      chrome: '#AEBAC2'         chromeLt: '#E6EAED'
  paper: '#F5F6F8'      ink: '#171A1E'            ink2: '#5B6470'
  success: '#2ECC71'
fontFamily:
  display: ['Saira Condensed', ...sans]   // H1–H3, uppercase
  num:     ['Saira', ...sans]             // цены/числа
  body:    ['Manrope', ...sans]
radius: cards/buttons 12–16px
```
Тип-масштаб (desktop): H1 56–72 / H2 30–48 / H3 23 / body 18 / small 14. Mobile H1 32–36.
Сигнатура бренда: красный «росчерк» (skew-плашка) и хром-хейрлайн — взять из макета.

## 5. Модель данных авто (`data/cars.ts`)
```ts
type Car = {
  id: string; model: string; year: number;
  country: 'kr'|'cn'|'jp'|'eu'; flag: string;
  engine: string; mileage: string; gearbox: string; drive: string;
  priceRub: number;       // цена под ключ
  status: 'in_stock'|'in_transit'|'on_order';
  image?: string;         // фото; если нет — рисуем SVG-силуэт
};
```
Демо-данные взять из `<script>` в `diauto69_site.html`. Цена форматируется как «4 290 000 ₽», крупно, бордовым.

## 6. Функциональность
- **Фильтр каталога** по странам (Все/КР/КН/ЯП/ЕС) + «показать ещё».
- **Формы заявки**: валидация (телефон обязателен), чекбокс согласия на обработку ПД.
  - Сабмит → серверный route (`app/api/lead/route.ts`) → отправка в **Telegram** через Bot API (`sendMessage` в чат менеджера). Токен и chat_id — из `.env` (`TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`), **не коммитить**. Запросить значения у заказчика; пока их нет — заглушка + `console.log`, форма показывает успех-тост.
  - Опционально продублировать на e-mail.
- Плавающая кнопка Telegram (контакт `@Dmitriicarexport`), якорная навигация, sticky-хедер.

## 7. Качество (Definition of Done)
- Полный адаптив: Desktop / Tablet / Mobile; кликабельные зоны ≥48px; видимый focus; `prefers-reduced-motion` уважается.
- Семантика и **SEO**: один H1, осмысленные H2, `alt` у изображений, `metadata` (title/description/OG), `sitemap.ts` + `robots.ts`.
- Lighthouse: Performance/Accessibility/SEO ≥ 90 на мобайле.
- Все секции в единой системе и узнаваемо перекликаются с логотипом (бордо/хром).
- `README.md` с командами запуска и описанием `.env`; код на TypeScript, без `any` без нужды.
- Деплой-конфиг под Vercel.

## 8. Чего НЕ делать без согласования
- Не подключать платные сервисы/аналитику и не вставлять реальные токены — запросить у заказчика.
- Не использовать чужие фото авто/лого брендов как контент сайта (только до момента, пока заказчик не пришлёт свои фото; иначе — SVG-силуэты из макета).
- Реквизиты, телефон, адрес в футере — плейсхолдеры, помеченные `TODO`, до подтверждения.

## Как запустить Claude Code

**Установка** (если ещё не стоит). Рекомендуемый нативный установщик — без Node.js:
- macOS / Linux / WSL: `curl -fsSL https://claude.ai/install.sh | bash`
- Windows (PowerShell): `irm https://claude.ai/install.ps1 | iex`
- Homebrew: `brew install --cask claude-code`
- Через npm (нужен Node.js 18+): `npm install -g @anthropic-ai/claude-code`

Нужна активная подписка Claude. Проверка: `claude --version`.

**Запуск задачи:**
1. Создайте папку проекта и положите туда `CLAUDE_CODE_TASK.md`, `diauto69_site.html`, `ТЗ_DI_AUTO_69_сайт.md`.
2. В этой папке выполните `claude` (первый раз попросит войти в аккаунт).
3. Вставьте промпт ниже.
