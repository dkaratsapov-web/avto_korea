# Telegram Mini App «ДиАвто69»

Мини-апп живёт на том же фронте, отдельным маршрутом: **`/tma`**
(на превью — `https://dkaratsapov-web.github.io/avto_korea/tma`).

Внутри: каталог (тот же источник данных, что и сайт/админка), фильтр по странам,
поиск, карточка авто с галереей, избранное и форма заявки. Подхватывает тему
Telegram, разворачивается на весь экран, использует нативные **BackButton** и
**MainButton** и тактильный отклик.

## Как подключить к боту

1. Создайте бота в **@BotFather** (`/newbot`), получите токен.
2. **@BotFather → /newapp** (или *Bot Settings → Web App*) и укажите URL мини-аппа:
   `https://<ваш-домен>/tma`. Можно повесить и на кнопку меню
   (*Bot Settings → Menu Button → URL*).

## Приём заявок (важно)

- Если мини-апп открыт через **кнопку reply-клавиатуры** (`web_app`), форма
  отправляет данные боту через `WebApp.sendData()` → ваш бэкенд бота ловит
  апдейт `message.web_app_data` (JSON: `{name, phone, car, source}`).
- Если открыт через **menu button / inline** — `sendData` недоступен, поэтому
  как запасной путь форма **открывает чат с менеджером** (`@Dmitriicarexport`).
  Для полноценного приёма из любого входа нужен **бэкенд бота** (Bot API),
  который примет заявку и/или перешлёт менеджеру.

## Хостинг

Тот же статический билд (GitHub Pages / Vercel / Cloudflare Pages). Telegram
требует **HTTPS** — GitHub Pages и перечисленные хостинги его дают.

> Дальше можно: авторизация по `initData` (валидация на бэкенде), хранение
> избранного на стороне бота, оплата через Telegram Payments, пуш-уведомления
> о статусе авто.
