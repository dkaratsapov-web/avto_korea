# ДиАвто69 — правила для Claude

Сайт, мини-апп, боты Telegram и MAX и CRM компании ДиАвто69 (Тверь, импорт авто из Кореи, Китая, Японии). Маркетинг ведёт karatsapov.ru.

## Перед работой
- Прочитать `context/handoff.md` — состояние проекта, открытые вопросы, ограничения.
- Устройство проекта — `docs/PROJECT.md`, как что делать — `docs/RUNBOOK.md`, история — `docs/HISTORY.md`.
- Контент Instagram — `context/brand-style.md`, `context/content-calendar.md`, план недели `context/week-*.md`.

## Как работаем
- **Максимальный автодеплой:** правка сразу уходит на сайт, без лишних вопросов. Пушить в обе ветки:
  `git push -u origin claude/telegram-promotion-page-9llr6e` и `git push origin HEAD:claude/beautiful-goodall-irzq2f` (основная ветка — она запускает деплой сайта и воркера).
- После деплоя проверять живой сайт: workflow «Site shots» (скриншоты и отчёт в ветке `site-shots`), «Site check» (SSL, ответы, вебхук). Сайт из облачной сессии напрямую не открывается.
- Ответы пользователю — по-русски, коротко, без технического жаргона.

## Нельзя
- Удалять что-либо из каталога без прямой просьбы.
- Просить или принимать токены и пароли в чате.
- Отдавать в интерфейс полный ключ CRM к боту (`crmAdminKey`).
- Ставить сервисы, которые «вычисляют» телефоны посетителей (пиксели вроде victorycorp.ru), и делать платное продвижение в Instagram.
- Добавлять внешний скрипт на сайт, не вписав его домен в CSP в `public/.htaccess` — иначе браузер его заблокирует.

## Проверки перед коммитом
- `npm test` (тесты воркера и утилит), `npx tsc --noEmit -p tsconfig.json`, `npm run build`, `php -l` для изменённых PHP.
- После перезапуска контейнера: `npm ci`. PDF из markdown: `python3.13 scripts/md-to-pdf.py in.md out.pdf`.
