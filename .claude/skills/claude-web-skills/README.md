# Claude Web Skills

One combined instruction file for building premium websites with Claude.

## Use it

Paste this link into a conversation with Claude and say "follow these instructions":

```
https://raw.githubusercontent.com/emanuelcira/claude-web-skills/main/SKILL.md
```

Or install it as a Claude Code skill:

```bash
mkdir -p ~/.claude/skills/claude-web-skills && curl -fsSL https://raw.githubusercontent.com/emanuelcira/claude-web-skills/main/SKILL.md -o ~/.claude/skills/claude-web-skills/SKILL.md
```
